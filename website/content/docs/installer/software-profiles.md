The installer offers profiles for common use cases: Developer, Gaming,
Creative, Maker/3D Printing, Remote Access, Virtualization, Office, Browsers & Chat,
System Tuning, and Input Method. In the installer's Software step, the profiles
are listed on the left and the selected profile's packages on the
right; check the ones you want, or press `a` to toggle every package
in the profile at once. There's also an "Install everything" toggle
for every profile in full.

Picking a profile doesn't install anything during the install session
itself. Selected packages are installed after first boot instead, so
the base install stays fast and minimal, and every profile installs
the same way whether or not it happens to contain an AUR package.
`archinstall`'s own silent install mode can only install official-repo
packages, so some profiles being "ready immediately" and others
delayed isn't actually avoidable if any of it happened during install.

Packages marked "(AUR)" are the ones built locally from the repository's
vendored snapshots instead of installed from Arch's official
repositories; that includes `sobarch-via-udev`, which is sobarch's own
package (a udev rule so a VIA-compatible keyboard can be configured
from its web app without root), not an AUR one. Installing
`vesktop-bin` also brings in a small launch wrapper that checks Vesktop's
Vencord files, as described in [AUR & Custom
Packages](../../packages/aur-and-custom/).

## Remote Access

The profile installs Sunshine (the streaming host) and Moonlight (the
client). Sunshine isn't started automatically: use **Super → System →
Remote Access** to start or stop it. On first run, open its web UI from
that menu (`https://localhost:47990`) to create the admin account, then
enter the PIN Moonlight shows under **PIN** in the web UI to pair. The
web UI port is closed in the firewall, so it's only reachable from the
machine itself.

**Add Virtual Monitor** in the same menu creates a separate 1920x1080
screen that exists only for Moonlight, parked where the cursor can't
reach it, and points Sunshine at it. Your real monitors and workspaces
stay as they are. It lasts until you remove it or restart Hyprland. It's
still your one session: windows and keyboard focus are shared with the
remote user.

To stream from outside your home network, put both machines on a VPN
such as Tailscale rather than forwarding ports.

## Installing a profile package later

Anything you skipped during install, or decide you want afterward, is
available from the desktop: **Super → Sobarch → Install Apps**. It's the
same combined install logic first boot already runs (official-repo
packages via `pacman`, AUR/custom packages via the [package sync
mechanism](../../packages/installing-updating/)), just for one package
at a time instead of a whole profile. Already-installed packages don't
show up in the list.
