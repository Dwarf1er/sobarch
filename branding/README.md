# Sobarch brand guide

The assets in this directory are the project's identity. They are
MIT-licensed with the rest of the repository, but the name and logo stand
for this project: please don't use them to suggest an unrelated project is
Sobarch or is endorsed by it.

## Files

| File | Use |
| --- | --- |
| `sobarch-logo.svg` | The logo mark. Preferred for anything that scales. |
| `sobarch-logo-compact.svg` | Small sizes, where the full mark loses detail. |
| `sobarch-logo-lockscreen.png` | 512 px raster, used by the lock screen. |
| `sobarch-wordmark.dur`, `sobarch-wordmark-ascii.txt` | The wordmark, as terminal art (the ly login screen uses it). |
| `sobarch-logo-ascii.txt` | The logo as terminal art. |
| `sobarch-wallpaper.svg`, `sobarch-wallpaper.png` | The default wallpaper. |
| `sobarch-social-preview.png` | The 1280x640 link-preview image. |
| `plymouth-sobarch/` | The boot splash theme. |

## Colors

Sobarch's look is the One Dark palette, applied consistently across the
desktop through the default theme.

| Role | Hex |
| --- | --- |
| Accent (the logo's blue, borders, highlights) | `#61afef` |
| Background | `#282c34` |
| Foreground | `#abb2bf` |

Other themes can be selected at any time from the theme menu; these three
values are what the logo and default wallpaper use.

## Typography

Terminal text and the fuzzel menus use D2CodingLigature Nerd Font.

## Using the logo

These are working guidelines rather than strict rules.

- Use the SVG where you can, and keep its proportions.
- Keep the accent blue on a dark background; on a light background, place
  it on a dark tile instead of recoloring it.
- Leave clear space around it of at least a quarter of its height.
- Don't stretch, rotate, outline, or add effects.
